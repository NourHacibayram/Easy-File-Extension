# Clipboard Gallery UI

The implemented popup and picker use a dark charcoal surface, a single muted sage accent, flat image previews, and underline tabs. Existing controls and IDs are preserved. System fonts avoid an extra remote request or font dependency.

- Shared tokens: `ui-theme.css`.
- Production UI snapshots: `clipboard-gallery-popup.png` and `upload-picker.png`.
- Generated design reference: `design-reference.png`, produced with the built-in ImageGen tool. The photos in that reference are examples; production displays the user's actual gallery and download thumbnails.
- Additional layout, empty, error, and selection snapshots: `tmp/ui-preview`, generated by `tests/render-ui.js`.

The initial light direction was replaced when the user requested a dark theme. The dark reference supplied the palette, type hierarchy, flat gallery treatment, and tab styling. The implementation keeps the popup at 420 × 600 and the upload dialog at up to 820 × 540, so spacing is more compact than the large conceptual reference. The picker also adapts to narrow widths.
